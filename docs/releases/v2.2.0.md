# VCX 2.2.0

VCX 2.2.0 is a backward-compatible feature release of the guided Windows x64
package. It builds on the 2.1.1 plug-and-play installation and improves media
selection and terminal workflows without changing the compression or subtitle
processing engine.

## Highlights

- Select multiple video files in the media browser. Press `space` to mark or
  unmark a file, `a` to add the highlighted folder recursively, and `r` to
  review the selection. Selection review supports removing an item with `x`
  and clearing the list with `c`.
- Multi-input configuration uses paths relative to a common input root. Existing
  configurations that specify only `input_root` remain supported.
- Review planned outputs and dependency readiness before a run. Long plans,
  dependency consent details, and software fallback warnings remain scrollable.
- Compact and wide terminal layouts keep progress, actionable errors, and
  essential controls visible, including when terminal colors are disabled.

## Install and offline behavior

Download `vcx-2.2.0-windows-amd64.zip` and its adjacent `.sha256` file from the
[VCX 2.2.0 GitHub Release](https://github.com/maucabreradev/video-compressor-extended/releases/tag/v2.2.0).
Verify the checksum, then extract the complete archive to a per-user directory
such as `%LOCALAPPDATA%\Programs\VCX`. No administrator rights or system `PATH`
changes are required.

The package bundles the pinned whisper.cpp runtime and default model with their
notices. FFmpeg/FFprobe remain consent-based, pinned downloads because the
selected GPLv3 build is not redistributed. A first run needs network access
unless the verified FFmpeg runtime is already cached. Offline setup reports
missing assets and does not start processing; verified cached assets continue
to work offline.

## Supported platform

- Windows x64.
- AMD AMF is selected only after a successful real capability probe. Otherwise
  VCX offers software H.264 with a performance warning and separate confirmation.
- Linux/VAAPI, macOS, Intel Quick Sync, NVIDIA/CUDA, and AV1 are not supported.
  Ubuntu CI validates source portability only.

## Acceptance

- The Windows x64 package was built twice with matching binary hashes and
  includes an external SHA-256 sidecar and internal file checksum manifest.
- Packaged AMF acceptance passed on Windows 11 Pro `10.0.26200` with an AMD
  Radeon RX 5500 XT, driver `32.0.21045.5002`, using manifest-pinned FFmpeg
  9.0.2.
- Clean-profile package and CLI acceptance passed in GitHub Actions on a Windows
  runner without usable AMF, exercising the confirmed software H.264 fallback.
  Contract tests alone do not prove GPU support.
