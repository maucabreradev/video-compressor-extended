# VCX 2.3.1

VCX 2.3.1 is a documentation-only maintenance release of the guided Windows x64
package. It adds Go API documentation and rationale for non-obvious recovery,
publication, and workspace-cleanup invariants. Runtime behavior is unchanged
from VCX 2.3.0.

## Install and offline behavior

Download `vcx-2.3.1-windows-amd64.zip` and its adjacent `.sha256` file from the
[VCX 2.3.1 GitHub Release](https://github.com/maucabreradev/video-compressor-extended/releases/tag/v2.3.1).
Verify the checksum, then extract the complete archive to a per-user directory
such as `%LOCALAPPDATA%\Programs\VCX`. No administrator rights or system `PATH`
changes are required.

The package bundles the pinned whisper.cpp runtime and default model with their
notices. FFmpeg/FFprobe remain consent-based, pinned downloads because the
selected GPLv3 build is not redistributed. A first run needs network access
unless the verified FFmpeg runtime is already cached. Offline setup reports
missing assets and does not start processing; verified cached assets continue
to work offline.

## Supported platform and behavior

- Windows x64.
- AMD AMF is selected only after a successful real capability probe. Otherwise
  VCX offers software H.264 with a performance warning and separate confirmation.
- Linux/VAAPI, macOS, Intel Quick Sync, NVIDIA/CUDA, and AV1 remain unsupported.
  Ubuntu CI validates source portability only.
- No media-processing behavior changed from VCX 2.3.0. Paths, cross-volume
  publication, and AMF claims remain limited to the evidence recorded for 2.3.0.

## Acceptance

- The Go source update adds comments only; it does not change runtime behavior.
- The Windows x64 package was built reproducibly with Go 1.25.0. Its pinned
  runtime assets, notices, archive manifest, and checksums were verified.
- Packaged AMF acceptance passed on Windows 11 Pro `10.0.26200` with an AMD
  Radeon RX 5500 XT, driver `32.0.21045.16010`, and manifest-pinned FFmpeg 9.0.2.
  Hardware support remains specific to the tested machine and driver.
- Packaged long-path, numbered-retry, and second-process recovery checks passed,
  including a 433-character Unicode destination and publication from C: to a
  distinct NTFS volume on F:.
- The 2.3.0-to-2.3.1 upgrade smoke test preserved per-user preferences, verified
  runtime assets, job manifests, workspaces, completed outputs, and source media.
- Offline dependency tests passed locally. Hosted Windows package CI passed the
  confirmed software H.264 fallback on a runner without usable AMF. Ubuntu CI
  passed as a source-portability check only.
