# VCX 2.0.0

VCX 2.0 is the Windows-only replacement for the legacy VCX 1.x application.
It provides a safer, resource-limited batch workflow for video compression and
optional subtitle generation.

## Highlights

- Interactive setup, planned-output review, and batch processing use the same
  application engine.
- AMD AMF H.264 encoding is supported when the real capability probe succeeds;
  HEVC is available only on hardware and FFmpeg builds that pass the probe.
- Outputs are validated before publication. Existing files and original media
  are not overwritten or deleted, and valid outputs can be resumed.
- Compression and Whisper subtitle generation are independent stages. Whisper
  is optional for compression-only use.
- Separate encode, subtitle, and Whisper CPU-thread limits keep resource usage
  configurable.

## Supported platform

- 64-bit Windows with an AMD GPU and a compatible driver. The selected encoder
  must pass `vcx doctor`'s real AMF probe.
- Linux is not supported or distributed in VCX 2.0. Ubuntu CI checks source
  portability only; Linux/VAAPI acceptance is deferred.

## External dependencies

- FFmpeg and FFprobe built with AMF support.
- For subtitles only, `whisper-cli.exe` from `whisper.cpp` and a separately
  obtained model file. VCX does not install or download these dependencies.

See `README.md` and `INSTALL.md` in the release archive for setup instructions.

## Hardware validation and benchmarks

Windows AMF acceptance used an AMD Radeon RX 5500 XT with driver
32.0.21045.5002 and FFmpeg 9.0. A real H.264 encode was validated at 1280x720
and 30 fps. A separate Sintel sample benchmark compared one and two encode
workers; results and limitations are in the
[Windows AMF benchmark report](https://github.com/maucabreradev/video-compressor-extended/blob/main/docs/benchmarks/windows-v2-rx5500xt-sintel.md).
Other GPU and driver combinations must pass the local capability probe before
use. No Linux/VAAPI support is claimed.
