# VCX 2.1.1

VCX 2.1.1 is a maintenance release of the guided Windows x64 package. It
clarifies installation and managed-model guidance and improves reliability of
the clean-profile package acceptance harness. The VCX runtime behavior and
managed runtime assets are unchanged from 2.1.0.

## Highlights

- The project README describes the current 2.1.1 package without internal
  backlog terminology and links directly to this release.
- The batch configuration example uses the managed Whisper model by default;
  `whisper_model_path` remains an optional override.
- The Windows acceptance harness preserves Go's configured caches while it
  isolates the synthetic user profile, avoiding unnecessary module downloads
  into that temporary profile.
- The package remains a per-user ZIP distribution. It bundles the pinned
  whisper.cpp runtime and multilingual `base` model with notices. FFmpeg/FFprobe
  remain pinned, consent-based downloads and are verified before use.

## Install and offline behavior

Download `vcx-2.1.1-windows-amd64.zip` and its adjacent `.sha256` file from the
[VCX 2.1.1 GitHub Release](https://github.com/maucabreradev/video-compressor-extended/releases/tag/v2.1.1).
Verify the checksum, extract the complete archive to a per-user directory such
as `%LOCALAPPDATA%\Programs\VCX`, and run `vcx.exe tui`. No administrator
rights or system `PATH` changes are required.

The first run needs network access to acquire FFmpeg/FFprobe unless they are
already cached. Setup requests consent before download. If offline, missing
assets are reported and media processing does not start; verified cached assets
work offline.

## Supported platform

- Windows x64.
- AMD AMF is selected only after a successful real capability probe. Otherwise
  the TUI offers software H.264 with an explicit performance warning and
  confirmation.
- Linux/VAAPI, macOS, Intel Quick Sync, NVIDIA/CUDA, and AV1 are not supported.

## Acceptance

- Clean-profile package acceptance and the packaged CLI workflow passed on
  Windows Server 2025 `10.0.26100` without usable AMF, using the real software
  H.264 fallback.
- AMF hardware acceptance passed on Windows 11 Pro `10.0.26200` with an AMD
  Radeon RX 5500 XT, driver `32.0.21045.5002`, using pinned FFmpeg 9.0.2.
- The release archive SHA-256 and CI acceptance results are recorded with the
  published release assets and workflow checks.
