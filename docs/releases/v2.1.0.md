# VCX 2.1.0

> Candidate release notes. Do not publish until Task 029 clean-profile and
> hardware acceptance is complete.

VCX 2.1.0 is the Windows x64 plug-and-play distribution of VCX 2.0. It keeps
the shared batch engine and provides a guided first-run package.

## Highlights

- Guided per-user archive installation; no administrator rights or system
  `PATH` changes are required.
- The package includes the pinned whisper.cpp Windows runtime and multilingual
  Whisper `base` model with redistribution notices.
- FFmpeg/FFprobe use a pinned HTTPS source and require explicit consent before
  download because the selected GPLv3 build is not bundled. Downloads are
  size- and SHA-256-verified.
- The TUI defaults to compression and subtitles, shows dependency preparation
  and readiness, and requires explicit confirmation for CPU-based H.264 fallback.
- The archive contains version/build metadata, an internal file checksum
  manifest, and an external SHA-256 sidecar.

## Install and offline behavior

Extract the checksum-verified archive into a per-user directory such as
`%LOCALAPPDATA%\Programs\VCX`, keep `runtime-assets` beside `vcx.exe`, and start
`vcx.exe tui`. The first run needs network access to acquire FFmpeg/FFprobe unless
they are already cached. An offline first run reports that setup is incomplete
and does not process media; verified cached assets work offline. See the
archive's `INSTALL.md` and `THIRD_PARTY_NOTICES.md`.

## Supported platform

- Windows x64.
- AMD AMF is selected only after the installed driver and FFmpeg pass the real
  capability probe. Otherwise VCX offers the explicitly confirmed software
  H.264 path.
- Linux/VAAPI, macOS, Intel Quick Sync, NVIDIA/CUDA, and AV1 are not supported.
