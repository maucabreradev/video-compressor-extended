# Video Compressor Extended (VCX)

Video Compressor Extended (VCX) is an open-source project focused on simplifying video processing workflows through command-line automation.

The project aims to provide a practical tool for processing multiple video files efficiently, reducing repetitive tasks and making media processing more accessible.

At this stage, the repository contains the initial project structure and documentation. Additional features and implementation details will be introduced as development progresses.

## Project Status

🚧 This project is currently under active development.
